# 東方スペルカード抽選器 (Touhou Spell Card Roulette)

東方Projectのスペルカードを条件付きでランダム抽選できるWebアプリケーションです。  
紅魔郷から最新作品まで、**全18作品・2,259枚**のスペルカードデータを収録しています。

お題プレイ、縛りプレイ、スペルカード鑑賞、練習ルーレットなどにご活用ください。

---

## 🌟 特徴

- **全18作品・2,259枚のスペルカードを網羅**
  - ナンバリング本編（整数作品: 紅魔郷 〜 獣王園）
  - 特殊ルート作品（妖精大戦争）
  - 撮影・外伝作品（文花帖、ダブルスポイラー、弾幕アマノジャク、秘封ナイトメアダイアリー）
- **高機能な絞り込みシステム**
  - 作品別選択（整数作品・外伝・妖精大戦争のワンタッチ一括選択対応）
  - 難易度別（Easy / Normal / Hard / Lunatic / Extra / Phantasm / Last Word など）
  - ボスキャラクター別選択（作品ごとのボス動的連動）
  - ステージ別・ルート別選択
  - 耐久スペルカードのみの抽出
- **クイックプリセット機能**
  - 「本編 (Normal)」「Extra / Phantasm」「全耐久スペル」「永夜抄のみ」「妖精大戦争」などを1クリックで即時セット
- **山札（デッキ）モード & 履歴機能**
  - 重複なしの連続抽選（山札が尽きると自動リシャッフルまたは終了）
  - 過去の当選履歴の確認・管理
- **外部データ連携**
  - 収録CSV（`SpellList.csv`）の自動読み込み & ローカルフォールバック内蔵
  - ユーザー独自のカスタムCSV読み込みに対応
- **サーバー不要・完全クライアント動作**
  - HTML/CSS/JavaScriptのみで構成されており、ブラウザ単体で軽量・高速に動作します。

## 🎮 使い方

### 1. ブラウザで直接利用する場合 (GitHub Pages)
リポジトリの GitHub Pages を有効化すると、以下のURLからインストール不要ですぐに利用できます：
`https://<ユーザー名>.github.io/<リポジトリ名>/`

### 2. ローカル環境で実行する場合
1. 本リポジトリをダウンロード（または `git clone`）します。
2. フォルダ内の `index.html` をお使いのブラウザ（Chrome, Edge, Firefox 等）でダブルクリックして開きます。
   *(※ローカルの file:// プロトコルでも内蔵データにより動作します)*

## 🛠️ 技術構成

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **ライブラリ**: [PapaParse 5.4.1](https://www.papaparse.com/) (CSV解析)
- **フォント**: [Google Fonts](https://fonts.google.com/) (M PLUS Rounded 1c, Noto Serif JP)

## 📁 ファイル構成

```text
TouhouSpellDice/
├── index.html        # アプリケーションのメインHTML
├── style.css         # スタイリング (和風ダークテーマ / レスポンシブ対応)

├── SpellList.xlsx    # データ編集用スプレッドシート
├── .gitignore        # Git除外設定
└── README.md         # 本ドキュメント
```
